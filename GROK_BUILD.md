# Grok Build entry (portable)

This repository is an **experimental** public product tree.

Local machine-specific builder briefs (absolute paths, session handoffs) live only on
maintainer machines under `docs/archive-local/` and are **not** part of the public clone.

**Public sources of truth:**
- `README.md`
- `docs/EXPERIMENTAL_STATUS.md`
- `docs/OPSEC_PUBLIC_RELEASE.md`
- `docs/V2_BUILD_PLAN.md`
- `docs/VISUAL_ASSISTANT_INSTRUCTION_SET.md`
- `docs/COMMIT_PLAN.md`

Run product work from the clone root with `npm install` / `npm run dev`.
